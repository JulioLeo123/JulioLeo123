## 📌 Featured Projects

### 🏗️ **Serverless Messaging System & Automated CRM (Biofase)**

Robust architecture focused on automating the post-sales flow and customer retention, integrating **Tiny ERP** with official messaging APIs.

* **High Availability Serverless Architecture:** Scalable orchestration using **AWS Lambda**, **API Gateway**, and **DynamoDB**, processing order events with high performance.
* **CRM & Intelligent Retention:** Implementation of communication rules via **AWS EventBridge**. The system performs dynamic scheduling for 30 and 60 days, with **automatic invalidation** logic: if the customer makes a new purchase, the promotional trigger is instantly canceled.
* **Compliance & Stability:** Migration of unofficial APIs to the **WhatsApp Business API (Gupshup/ChatGuru)**, ensuring compliance with Meta guidelines and institutional security.
* **UX & Business Intelligence:** Application of a 48-hour intelligent *delay* for delivery notifications, ensuring that communication arrives only after confirmation of physical receipt.
* **Monitoring and Security:** Permission management via **AWS IAM** and real-time monitoring through **Amazon CloudWatch**.

### 🌐 **Open Data São Bento do Sul**
Public transparency platform for the local community.
- **Stack:** Java 21 (Spring Boot), React, PostgreSQL, and Hasura GraphQL.
- **Infrastructure:** Orchestrated deployment via Docker and Shell Scripts.

### 🎾 **Court Reservation API**
Backend for managing sports scheduling.
- **Stack:** PHP, RESTful API, Android Studio.
- **Highlight:** Complete documentation via **Swagger** and focus on business rules for high concurrency of time slots.
