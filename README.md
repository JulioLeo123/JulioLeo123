## 📌 Projetos em Destaque

### 🏗️ **Sistema de Mensajeria Serverless (Biofase)**
Sistema complexo que integra **Tiny ERP** com APIs oficiais (ChatGuru/Gupshup).
- **Stack:** Python, AWS Lambda, DynamoDB, EventBridge.
- **Destaque:** Implementação de réguas de retenção com agendamentos automáticos e lógica de cancelamento de mensagens baseada em novas compras.
- **Logística:** Web Scraping em Python para rastreio automático e inteligência de delay de 48h para notificações de entrega.

### 🌐 **Dados Abertos São Bento do Sul**
Plataforma de transparência pública para a comunidade local.
- **Stack:** Java 21 (Spring Boot), React, PostgreSQL e Hasura GraphQL.
- **Infra:** Deploy orquestrado via Docker e Scripts Shell.

### 🎾 **API de Reserva de Quadras**
Backend para gestão de agendamentos esportivos.
- **Stack:** PHP, API RESTful.
- **Destaque:** Documentação completa via **Swagger** e foco em regras de negócio para alta concorrência de horários.
